# Text Agent

Консольный диалог с языковой моделью через [ProxyAPI](https://proxyapi.ru/). История сообщений хранится в программе и отправляется с каждым следующим запросом, поэтому модель видит предыдущий контекст, пока вы не выйдете или не очистите чат.

При запуске выбирается режим:

| Клавиша | Режим | Модель |
| --- | --- | --- |
| Enter или `1` | Думающая, по умолчанию | `anthropic/claude-sonnet-5-5` |
| `2` | Обычная | `openai/gpt-5.6-luna` |

В думающем режиме Claude отвечает через `/v1/messages`. Если в ответе есть краткое размышление, оно печатается отдельным блоком перед текстом ответа. Обычный режим использует Chat Completions.

## Запуск

Нужен Python 3.12.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Создайте файл `.env` в корне проекта:

```text
OPENAI_API_KEY=ваш-ключ-proxyapi
OPENAI_BASE_URL=https://api.proxyapi.ru/v1
```

Ключ берётся в личном кабинете ProxyAPI. Файл `.env` не коммитьте: он указан в `.gitignore`.

Другую обычную модель можно задать переменной `OPENAI_MODEL`.

Запуск:

```powershell
python text_agent.py
```

## Команды в диалоге

- `/reset` — очистить историю и начать разговор заново
- `/exit` — выйти
